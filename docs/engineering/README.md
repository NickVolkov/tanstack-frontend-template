# Frontend engineering guides

These guides define the target architecture for projects generated from this template. They are portable: examples refer to the abstract Article domain, not to a product repository.

## Read by task

| Change                                   | Read                                                                                  |
| ---------------------------------------- | ------------------------------------------------------------------------------------- |
| Any application feature                  | [Frontend guidelines](frontend-guidelines.md)                                         |
| Queries, mutations, pagination, SSR data | [Server-state cache](server-state-cache.md) and [Queries and API](queries-and-api.md) |
| Form                                     | [Forms](forms.md)                                                                     |
| Dialog, drawer, sheet                    | [Modals and overlays](modals.md)                                                      |
| List or feed                             | [Lists](lists.md)                                                                     |
| Test or mock                             | [Testing](testing.md)                                                                 |
| Review or refactor                       | [Anti-patterns](anti-patterns.md)                                                     |

The [`canonical-app`](canonical-app/README.md) is executable specification. If prose and code disagree, resolve the contradiction rather than copying either blindly.
